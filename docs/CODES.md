# The codes: who makes them, who dials them, what they do

Written because the founder asked the right question: what does a person
actually dial, and who makes the code. There are four kinds of code in this
product and only one of them is ours to invent.

## 1. The network's airtime transfer code. Theirs, not ours

When a sender moves airtime from their own line to one of our receiving
numbers, they dial **their own network's transfer code**. MTN, Airtel, Glo
and 9mobile each own their code, publish it, change it when they like, and
charge their own fee and daily cap on it. Nobody else can make one, and no
software can move airtime off a customer's line without it, because the
networks give nobody an interface for that. This is the whole reason the
product is built the way it is.

What we do with those codes:

- The exact code for each network is a runtime setting in the command
  centre, under Settings, Networks, "Transfer code the sender dials". It is
  a template: `*600*{pin}*{amount}*{number}#`. Data gifting has its own
  template beside it.
- The sender's page fills in the amount and our receiving number, and
  shows the word PIN where their PIN goes. **We never hold a PIN.** A
  template with four or more digits in a row and no `{pin}` in it is
  refused when saved, because that is somebody typing a PIN into a box it
  must never be in.
- On Android the code is a link the dial pad opens. On iPhones, which
  refuse to dial stars and hashes from a link, the page shows the code
  large with a copy button and plain words.

When a network changes its code, you change one setting and every sender
sees the new one. No deploy.

The same is true in the other direction. When somebody **sells** us airtime
or data at `/sell`, they dial their own network's transfer or gifting code
to our number, exactly as a sender does. There is no code we could give
them that would take value off their line, which is why the seller always
dials it themselves, and why the page says in so many words that the number
shown is ours.

## 2. Our own references. Ours, made by us

- A transfer reference, shown to the sender so they can check on it.
- An order reference for a purchase, `RT-` and eight characters.
- A list reference for a shop's bulk purchase, `BK-` and eight characters.
- An agent's code, five characters, and their link `/a/<code>`.
- A top-up reference for an agent paying us, `AT-` and six characters.
- A sale to us, `SB-` and eight characters, and the credit code it earns,
  `CR-` and ten characters. A credit code is money to whoever holds it, so
  it is ten characters from the same alphabet rather than eight.

All of these are made on our server from the operating system's own random
number source, in an alphabet with no 0, O, 1, I or L in it, so a person
can read one aloud down a phone line without being misheard. None of them
is a number counted upwards, because a counted number tells anybody holding
one how many customers we have and lets them guess the next one.

## 3. The codes a buyer uses to pay us. Their bank's, not ours

A customer buying airtime or data **from** us dials nothing to buy it. They
open the page, choose the network, the number and the amount, and pay one of
four ways:

- **Bank transfer** to our account, with their order reference as the
  narration. The account details are settings in the command centre.
- **Card**, through the card gateway, which is Flutterwave where its keys are
  set. A card issued outside Nigeria works as well as one issued inside it.
- **Their bank's USSD payment code**, also through the gateway. That code, for
  example `*737*...#` for one bank, belongs to the buyer's own bank and is
  generated by the bank, not by us. The gateway routes the payment to us.
- **A credit code** we gave them for airtime or data they sold us.

So a buyer with no data at all can still pay by USSD, but only if somebody
else, or a printed poster, gives them the order reference first. Which is
why the fourth kind of code matters.

## 4. A short code of our own, for example `*347*88#`. Ours to run, theirs to lease

The code itself is leased, and that part cannot be written in code. It needs:

- a USSD aggregator with a Nigerian Communications Commission licence, and
  through them a connection to each of the four networks;
- a monthly fee for the code and a per session cost;
- an agreement with each network, which is the slow part.

**Everything on our side of that lease is built and tested.** The aggregator
sends us one keypress at a time and we answer with one screen; that endpoint,
the menus behind it, and the record of every session are all in this
repository and are described in docs/USSD.md. The day a contract is signed,
the work is: put the shared secret in the environment file, type the code
into Settings, Dial service, and turn it on.

What a caller can do from a dial pad with no data at all: send airtime to
another network, sell airtime to us for credit, buy airtime, check a
transfer, and read their last few sends. The pricing, the caps, the ledger,
the pools and the delivery are the same code the website uses, so a rule
changed in the command centre changes the dial code at the same moment.

The lease is item 15 in docs/WAITING_ON_FOUNDER.md. Until an aggregator is
signed, the honest position is: **buying from us works today from the page,
with card, bank transfer or the buyer's own bank USSD code; moving airtime
off a customer's line will always be the network's own code, dialled by the
customer; and our own short code waits on a contract, not on software.**

## What the person buying from us with credit dials

Nothing. A credit code is typed into the Buy airtime page, not into a dial
pad. It is not a recharge voucher and it will not work on a network's own
`*555*` style menu: it is credit with us, spendable on any network.

## What an agent's shop dials

Nothing. An agent buys for a walk-in customer from their own portal page,
or, if the shop runs its own till software, through the interface described
in docs/AGENT_API.md with a key they make themselves. Both of those charge
the shop's wallet and deliver the airtime the same way.
